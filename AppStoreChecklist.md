# RunBoy App Store Deployment Checklist

Before you submit RunBoy to the App Store, complete the following:

1. App metadata
- Final game name
- Subtitle
- Keywords
- Category and age rating
- Privacy policy URL

2. Branding and visuals
- Final App Icon set
- Launch Screen design
- In-game title screen design
- Game-over polish and HUD refinement

3. iOS app configuration
- Bundle identifier
- Team / Apple Developer account
- Signing certificates
- Provisioning profiles
- Xcode target configuration

4. Store testing
- TestFlight internal testing
- Device testing on multiple iPhone sizes
- Beta feedback pass
- Crash and performance review

5. Release preparation
- Final screenshots for App Store listing
- App preview video
- Release notes
- Version number and build number
- Submit for review

6. Optional production improvements
- Sound effects and music
- Additional power-ups
- Tutorial overlay
- Endless difficulty tuning
- Leaderboard and achievements

This checklist keeps the project aligned with App Store submission requirements.
